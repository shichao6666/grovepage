# 森页护眼 · 隐私政策

森页护眼在浏览器内应用网页滤镜并安排休息提醒。扩展为判断当前网站是否适用滤镜，读取打开页面的地址并在浏览器内与网站规则匹配。

- 网站规则、提醒设置和滤镜强度保存在浏览器的扩展存储。颜色和界面语言偏好可能按浏览器的扩展同步设置在设备之间同步。
- 扩展不收集浏览历史、网页内容或使用统计，不向项目维护者的服务器发送数据。
- 选择导出时，扩展会生成一份本地 JSON 配置，可能包含你填写的网站名单和提醒提示语。导入只读取你主动选中的文件。
- 点反馈邮箱会打开邮件客户端。扩展内的「捐献支持」展示随扩展打包的收款码图片。付款由支付应用处理，扩展不收集付款信息。
- 可在高级设置中修改已保存的偏好，或卸载扩展以清除本机扩展数据。已导出的文件由你管理。

# GrovePage Privacy Policy

GrovePage applies website filters and schedules break reminders in Microsoft Edge and Google Chrome. It reads the addresses of open pages to match them against site rules within the browser.

- Site rules, reminder settings, and filter strength are stored in browser extension storage. Color and interface language preferences may sync across devices according to the browser's extension sync settings.
- GrovePage does not collect browsing history, page contents, or usage analytics. It sends no data to servers operated by the project maintainers.
- Export creates a local JSON configuration that may contain the site rules and reminder text you entered. Import reads only the file you select.
- The feedback link opens your email client. The in-extension Support page displays bundled QR images. Your payment app handles any payments, and the extension does not collect payment information.
- You can edit preferences in Advanced settings or uninstall GrovePage to remove its local extension data. You manage any exported files.
