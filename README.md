# 森页护眼 · GrovePage

简体中文 | [English](README.en.md)

**森页护眼（GrovePage）** 是一款适用于 **Microsoft Edge** 和 **Google Chrome** 的开源浏览器扩展（Manifest V3），为网页提供柔和可调的护眼色彩滤镜，并内置休息提醒与全屏休息功能。所有功能免费、纯本地运行，不收集任何浏览数据。

---

## 核心功能

- **多色护眼滤镜**：内置 12 种预设护眼色，并支持自定义 RGB 选色；首次安装默认开启，重启浏览器或后台休眠后始终记住你最后一次手动开关选择。
- **精细强度与昼夜时段**：滤镜不透明度由 40% 基础值与 0–100% 滑块（对应 60% 调节区间）组成；可在高级设置中开启「昼夜滤镜强度」，按设备本地时间自动切换白天与夜间强度（默认关闭）。打印网页或另存为 PDF 时自动隐藏滤镜。
- **网站规则与状态检测**：支持「所有网站」「指定网站」「排除网站」三种模式（指定模式需至少填写一个有效域名），弹窗实时显示当前页面的滤镜应用状态。
- **临时暂停**：浏览图片或截图时，可一键暂停当前标签页或所有标签页的滤镜（30 秒至 5 分钟），仅限当前浏览器会话，到期后按全局开关和网站规则自动恢复。
- **休息提醒与全屏休息**：支持固定间隔与倒计时两种方式，可自定义提示语。普通提醒 5 秒后自动关闭；也可开启全屏强制休息与三段内置轻音乐（支持试听与音量调节）。
- **多语言与快捷键**：支持简体中文、English、日本語、한국어、ភាសាខ្មែរ、Русский 6 种界面语言；支持自定义快捷键（默认 `Alt+Shift+Q`，需在高级设置中启用）。
- **配置备份与恢复**：高级设置支持将偏好导出为 JSON 文件（不含运行中的临时暂停或计时）；导入前先校验格式并展示逐项变更预览，确认后再应用。

## 安装与使用

### 从源码本地加载

1. 下载本仓库源码，或解压发布页中的 `grovepage-v1.0.0-github-source.zip`。
2. 打开 `edge://extensions` 或 `chrome://extensions`，开启右上角**开发人员模式**。
3. 点击**加载解压缩的扩展**，选择本项目中的 `extension/` 文件夹即可使用。
4. 更新本地文件后，在扩展管理页或扩展的「关于」页点击**重新加载扩展**（保持目录位置不变即可保留本机已有设置）。

> 最低浏览器版本要求：Chromium 105+（Edge 105+ / Chrome 105+）。

## 隐私与权限

森页护眼不收集浏览历史、网页内容或使用统计，也不向任何外部服务器发送数据。网站规则、提醒和滤镜强度保存在浏览器本地存储；颜色和语言偏好可随浏览器扩展同步。

详情请阅读 [隐私政策（PRIVACY.md）](PRIVACY.md)。

## 开发与构建

项目不依赖外部前端构建工具，图标与背景音均由标准库 Python 脚本生成：

```bash
# 重新生成扩展图标（16/32/48/128）和三段 WAV 背景音
python -B tools/generate_assets.py

# 构建 Edge、Chrome 商店发布包、GitHub 源码包及 SHA-256 校验清单（输出至 dist/v1.0.0/）
python -B tools/build_release.py
```
